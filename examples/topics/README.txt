# Topics

Each topic shows one feature on open datasets from [gstvschlz/datasets](https://github.com/gstvschlz/datasets).
Topics 1 to 60 follow the workflow: data, transforms, variography, estimation, change of support, simulation,
validation, modeling, then I/O and scale; topics 61 onward add methods across all of these. Walker Lake has an
exhaustive grid, so its results are checked against the truth. Every page runs when the site is built.
