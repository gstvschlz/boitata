    plot3d ¶

    3D views on pyvista (the 3d extra).

    to_pyvista converts a container to a pyvista dataset with its attributes as point or cell data; the plotting functions add it to plotter when given, else to a new one, and return the plotter.

    BlockModel ¶

    Regular or masked grid of blocks, 2D or 3D, optionally rotated.

    centroids property ¶

    centroids

    (n, 3) cell centers in world coordinates.

    corners property ¶

    corners

    (n, 8, 3) world-space corners of each row's box: vertex c (0..8) takes the row's minimum extent on axis a if bit a of c is 0, its maximum if 1.

    extents property ¶

    extents

    (n, 6) sub-block extents as fractions of the parent cell [u0, v0, w0, u1, v1, w1], or None when not sub-blocked.

    index property ¶

    index

    Parent cell index of each row (masked or sub-blocked), or None when regular.

    volumes property ¶

    volumes

    Volume of each row (area with unit height in 2D).

    discretize method descriptor ¶

    discretize(n)

    Nodes discretizing every block, e.g. targets for simulate(blocks=).

    Parameters:

    Name Type Description Default
    n int or sequence of int

    Nodes per axis inside each block; an int applies to x, y and z, or to x and y only in a 2D model.

    		 required

    Returns:

    Type Description
    BlockModel

    A masked grid n times finer, or for a sub-blocked model each sub-block split into n per axis. Its one column, block, is the row in this model of each node.

    from_extents staticmethod ¶

    from_extents(
    *objects,
    size,
    buffer=Ellipsis,
    rotation=None,
    snap=Ellipsis,
    crs=None,
)

    Smallest regular grid holding every object plus a buffer.

    Parameters:

    Name Type Description Default
    *objects (PointSet, Drillholes, Mesh, Polylines, BlockModel or array_like)

    What the grid must cover: points, drill hole paths, mesh or line vertices, the corners of another grid, or (n, 2)/(n, 3) coordinates.

    		 required
    size sequence of float

    (dx, dy, dz) block size. With (dx, dy) or dz=None the grid is 2D: one layer spanning the buffered z range.

    		 required
    buffer float or sequence of float

    Margin added on each side, one value or one per grid axis.

    		 0.0
    rotation tuple of float

    Azimuth, dip and rake in degrees; the extents are measured along the rotated grid axes.

    		 None
    snap bool, float or sequence of float

    Put the origin on a multiple of this step, measured along the grid axes, so grids built from different data line up; True snaps to the block size.

    		 False
    crs str
    		None

    Returns:

    Type Description
    BlockModel

    A regular model without attributes, with the fewest blocks along each axis that hold every point.

    mask method descriptor ¶

    mask(keep)

    regularize method descriptor ¶

    regularize(target, *, min_fraction=0.0)

    Columns of this model averaged onto the blocks of target.

    Each row of this model counts in a target block by the volume they share, from exact box overlaps, so it works both ways between regular, masked and sub-blocked models: to a coarser grid, sub-blocks to their parents, or a regular estimate onto sub-blocks.

    Parameters:

    Name Type Description Default
    target BlockModel

    Blocks to average onto, with the same rotation (the origin and sizes may differ). Its own columns are kept.

    		 required
    min_fraction float

    Blocks less covered than this are null.

    		 0.0

    Returns:

    Type Description
    BlockModel

    target with every column of this model: floats as volume-weighted means of the non-null rows, other columns (text, integers) as the value filling the most volume, ties to the smallest, nulls not voting. fraction is the share of each block covered by this model, so volumes * fraction * grade sums to this model's volumes * grade.

    subblock method descriptor ¶

    subblock(meshes, subgrid, *, column='domain', fill=None)

    Sub-blocks every block by prioritized meshes.

    Each block is split on a regular subgrid; each sub-cell takes the label of the first domain holding its center. Blocks of one label stay whole, others keep runs of sub-cells merged along x, then y.

    Parameters:

    Name Type Description Default
    meshes sequence of (Mesh or Polylines, str, str)

    (mesh, rule, label) in priority order, the first match winning. rule is "inside" a closed mesh, or "below" or "above" a surface such as topography, along world z; off the surface's footprint neither matches. Polylines take "inside" only: the vertical prism over their features, as Polylines.contains.

    		 required
    subgrid int or sequence of int

    Sub-cells per axis, which sets the smallest sub-block; an int applies to x, y and z, or to x and y only in a 2D model.

    		 required
    column str

    Name of the label column.

    		 "domain"
    fill str

    Label of the sub-cells no domain holds; without it they are dropped.

    		 None

    Returns:

    Type Description
    BlockModel

    Sub-blocked model on subgrid with the label column and the columns of each sub-block's parent block.

    Drillholes ¶

    Collar, survey and interval tables desurveyed by method: "minimum_curvature" (circular arcs), "tangential" (each survey's direction holds down to the next) or "balanced_tangential" (half of each segment along each end's direction). Survey angles are azimuth (clockwise from north) and either dip (degrees below horizontal) or inclination (degrees from vertical); holes without survey are vertical.

    interval_columns property ¶

    interval_columns

    Hole, from and to column names of the interval table, if one was given.

    at method descriptor ¶

    at(holes, depths)

    (n, 3) positions at measured depths down holes, e.g. contacts.

    composite method descriptor ¶

    composite(
    length,
    grades,
    *,
    domain=None,
    intervals=None,
    residual="keep",
    min_fraction=0.5,
    categories=Ellipsis,
)

    Length-weighted composites, never crossing a change of domain and located at their midpoints. Composites with none of the grades sampled are dropped. Each grade comes with its sampled length, <grade>_length, so the sum of grade × <grade>_length equals the input metal; length also counts unsampled ground. The hole column keeps its constructor name, followed by from, to and length.

    Parameters:

    Name Type Description Default
    length float or None

    Composite length in meters; None gives one composite per run of domain.

    		 required
    grades sequence of str

    Numeric columns, averaged over the length that carries a value.

    		 required
    domain str

    Column whose changes composites never cross.

    		 None
    intervals table

    Hole, from and to columns (named as in the constructor) of non-overlapping intervals to composite to instead of length, e.g. benches; ground outside them is left out.

    		 None
    residual (keep, drop, merge)

    What to do with the tail of a run shorter than min_fraction * length; merge adds it to the previous composite of the run, if there is one.

    		 "keep"
    min_fraction float

    Tail length, as a fraction of length, below which residual applies.

    		 0.5
    categories sequence of str

    Categorical columns, composited to the value covering the most length.

    		 Ellipsis

    mesh_intervals method descriptor ¶

    mesh_intervals(mesh, *, step=1.0, tolerance=0.01)

    Splits each hole's path against a closed mesh, wherever it crosses the surface.

    The path is sampled every step of depth and a crossing between two samples is bisected down to tolerance; a boundary crossed more than once within one step is missed. Every depth down every hole falls in exactly one row, so piping the result through merge_intervals splits assays exactly at the mesh instead of at a logged contact.

    Parameters:

    Name Type Description Default
    mesh Mesh

    A closed mesh.

    		 required
    step float

    Sampling step down each hole, in meters.

    		 1.0
    tolerance float

    Depth tolerance the crossing is refined to, in meters.

    		 0.01

    Returns:

    Type Description
    Table

    Hole (named as in the constructor), FROM, TO and INSIDE (whether the run is inside mesh), one row per run down each hole — matching merge_intervals's own column names.

    paths method descriptor ¶

    paths()

    Desurveyed stations: hole (named as in the constructor), depth, x, y, z.

    runs method descriptor ¶

    runs(
    grade,
    *,
    cutoff=None,
    category=None,
    ore=Ellipsis,
    min_length=0.0,
    max_dilution=0.0,
    edge=0.0,
)

    Ore and waste runs down each hole: contiguous intervals above cutoff (or of an ore category), cleaned by mining rules. The runs of a hole partition its samples, so Σ grade × length equals the sample metal.

    Rules apply in order: internal dilution, then edge dilution, then minimum length. Samples missing the grade are left out, as unsampled ground, and samples missing the category are waste; like composite(None, ...), gaps are skipped, not bridged.

    Parameters:

    Name Type Description Default
    grade str or None

    Numeric column; None with category for runs without grades.

    		 required
    cutoff float

    Samples at or above it are ore, unless category is given; also the grade a run must keep when it takes in internal dilution.

    		 None
    category str

    Column whose values in ore flag ore samples.

    		 None
    ore sequence of str

    Ore values of category.

    		 Ellipsis
    min_length float

    Runs spanning less, shortest first, take their neighbors' flag and merge with them.

    		 0.0
    max_dilution float

    Waste runs between ore spanning at most this are taken into the ore when the grade of the three together stays at or above cutoff.

    		 0.0
    edge float

    Waste taken into each ore run on each side where it meets waste.

    		 0.0

    Returns:

    Type Description
    Table

    Hole (named as in the constructor), from, to, length (sampled length), the grade, and ore, one row per run down each hole.

    repair method descriptor ¶

    repair(*, tolerance=0.0)

    Weld close vertices, drop degenerate and duplicate triangles, and wind the triangles consistently.

    Parameters:

    Name Type Description Default
    tolerance float

    Vertices within this distance of an earlier vertex merge into it; 0 merges exact duplicates only.

    		 0.0

    Returns:

    Type Description
    Mesh

    A new mesh without unused vertices, each connected piece wound one way. A closed piece inside an even number of other closed pieces winds outward; inside an odd number it is a cavity and winds inward, so the volume is outer minus cavities. Kept vertices and triangles keep their order and attributes. Repairing it again changes nothing.

    vertical_distance(points)

    Signed vertical distance to a surface such as topography.

    Parameters:

    		 required

    Returns:

    Type Description
    ndarray
