    EDA and validation¶

    describe(values, weights=None, quantiles=Ellipsis) builtin ¶

    Weighted (declustered) statistics of values; NaN is skipped.

    Returns:

    Type Description
    dict

    n, mean, variance, std, cv, min, max and quantiles at the given probabilities (mid-point cumulative weights).

    swath(coords, values, width, azimuth=None, axis=None, weights=None) builtin ¶

    Mean of values per slice of width along azimuth (degrees from north) or axis ("x", "y", "z"); slices start at 0 so swaths of samples and blocks line up.

    Returns:

    Type Description
    dict

    centres, mean and count of the non-empty slices.

    contact(coords, values, domains, holes, inside, outside, max_distance, bin) builtin ¶

    Mean of values against signed distance to the inside/outside contact along each hole, negative inside.

    Returns:

    Type Description
    dict

    distance (bin centres), mean and count.

    capping(values, weights=None, caps=None) builtin ¶

    Metal removed and statistics after capping at each of caps (default: weighted quantiles 0.9, 0.95, 0.975, 0.99, 0.995, 0.999).

    Returns:

    Type Description
    dict

    cap, fraction of weight above it, metal_removed (1 - capped mean / mean), capped mean and cv.

    h_scatter(coords, values, lag, tolerance, azimuth=None, dip=0.0, angle_tolerance=22.5, other=None) builtin ¶

    Head and tail values of pairs lag ± tolerance apart, and their correlation.

    With azimuth, pairs are oriented within angle_tolerance of (azimuth, dip); without, omnidirectional. Tails come from other when given.

    correlation(data, weights=None, method='pearson') builtin ¶

    Correlation matrix of the columns of data, each pair over rows without NaN.

    global_bias(estimate, data, weights=None, data_weights=None) ¶

    Means of an estimate and of the data it came from, weighted by e.g. block volumes and declustering weights, and the relative difference estimate / data - 1.

    classify(criteria, rules, default='unclassified') ¶

    Labels each block with the first rule whose conditions all hold.

    Parameters:

    Name Type Description Default
    criteria dict of str to array_like

    Per-block metrics, e.g. slope, efficiency from predict(..., diagnostics=True) and nearest_dist, n_holes from neighborhood_stats.

    		 required
    rules sequence of (str, dict)

    (label, {metric: (op, threshold)}) in priority order; op is one of <, <=, >, >=. NaN never satisfies a condition.

    		 required
    default str

    Label where no rule holds.

    		 'unclassified'

    Examples:

    >>> classify(d, [("measured", {"slope": (">=", 0.8), "n_holes": (">=", 3)}),
...              ("indicated", {"slope": (">=", 0.5)})], default="inferred")

    smooth_classes(model, classes, window=Ellipsis, iterations=1) builtin ¶

    Majority filter of block classes over a window of cells, repeated iterations times; ties keep a block's class and absent cells do not vote. Classes may be any labels; the result has the same labels.
